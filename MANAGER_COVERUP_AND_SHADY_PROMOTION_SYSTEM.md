# Manager Coverup And Shady Promotion System

## Purpose

Managers can also be shady. The player can benefit, refuse, expose, or leverage the situation.

## Manager Coverup Examples

- covers up missing inventory
- blames New Hire
- blames player
- changes schedule after the fact
- deletes bad complaint
- pretends camera is broken
- hides inspection issue
- uses staff tips for team fund
- protects favorite employee
- blocks promotion
- offers player deal to stay quiet
- rewrites incident report
- tells player to say register was down
- gives fake raise promise
- threatens worse shifts
- offers promotion for loyalty

## Player Routes

- go along
- refuse
- report manager
- use it as leverage
- save evidence
- tell coworker
- tell corporate
- cartoon blackmail leverage
- pretend not to know
- help coverup for promotion boost
- expose manager during inspection
- side with staff

## Shady Promotion Outcomes

Promotion is not simple morality.

Possible manager paths:
- Clean Manager
- Staff Hero Manager
- Corporate Pet Manager
- Shady Manager
- Chaos Manager
- Last Option Manager
- Blackmail Manager
- Liability Manager

## Rule

The player can become manager while suspicious, but caught behavior has real consequences.
