# Phase 2 — Interaction + Pickup/Drop

## Goal
The player can look at an object, see/trigger interaction, pick it up, drop it, and avoid softlocks.

## Tasks
- Verify RayCast3D from camera.
- Add interaction prompt if missing.
- Make one pickup item in scene.
- Pick up/drop with keyboard and controller actions.
- Add lost item fallback.
- Log pickup/drop to EventLog.

## Acceptance
- Player can pick up and drop at least one item in the 3D scene.
