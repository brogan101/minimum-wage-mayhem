# Slapstick Brawl System

## Purpose

Add rare cartoon workplace disaster incidents where conflict escalates into a slapstick scramble.

This is not realistic combat. It is a non-gory, consequence-driven workplace disaster mini-event.

## Escalation Ladder

1. Complaint
2. Raised voice
3. Refuses to leave
4. Demands manager
5. Food/drink throw
6. Counter slapstick scramble
7. Random object brawl
8. HR report
9. Viral clip/corporate response

## Player De-Escalation Options

- Use Manager Voice
- Offer fresh fries
- Offer coupon
- Sauce peace offering
- Ask to pull forward
- Call manager
- Hit panic button
- Use customer-service stare
- Print receipt as distraction
- Say “Sir, this is a drive-thru”
- Let coworker handle it
- Try to be the bigger person

## Rules

- Brawls are rare.
- Tutorial blocks brawls.
- Most conflicts should resolve before brawl.
- Objects are goofy, not dangerous.
- Player violence is penalized.
- Nonviolent/comedic options should be best long-term.
- Outcomes feed HR, reviews, reputation, promotion/demotion, and recap.
