# Phase 5 — Full Mini Shift

## Goal
Three-customer MVP shift with results.

## Tasks
- Serve 3 customers.
- Add simple customer variance using 50/25/12/8/5 tier system.
- Add one employee call-out or workday modifier.
- Add shift timer/end condition.
- Generate results screen/log.
- Generate one review and one HR report from EventLog.
- Save progress locally.

## Acceptance
- Player can complete a mini shift from start to results.
