# Suspicion And Detection System

## Purpose

Track whether the player, NPC coworkers, or managers are becoming suspicious enough to trigger investigation, HR reports, write-ups, promotion delays, demotion, or firing routes.

## Tracked Values

- player_suspicion
- current_witnesses
- camera_coverage
- manager_suspicion
- corporate_audit_risk
- coworker_snitch_chance
- customer_report_chance
- evidence_flags
- repeat_behavior
- active_writeups
- shady_reputation
- tip_jar_discrepancy
- register_discrepancy
- inventory_discrepancy
- food_safety_risk
- workplace_conflict_risk
- impairment_suspicion
- hr_investigation_status

## Detection Roll Factors

More likely caught:
- manager nearby
- Corporate Climber nearby
- customer watching
- camera active
- high suspicion
- repeated action
- corporate inspection
- secret shopper
- coworker dislikes player
- strict manager archetype
- Walking HR Report reputation
- low chaos shift

Less likely caught:
- shift is chaotic
- checked-out manager
- cameras broken
- coworker likes player
- high staff loyalty
- small action
- evidence lost in bigger incident
- corporate distracted
- shady manager
- high performance score

## Rule

Detection should never provide evasion instructions. It is a fictional probability system.
