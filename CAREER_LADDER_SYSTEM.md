# Career Ladder System

## Purpose

Progression must feel like a real fast-food job ladder, not just an XP number.

The player should unlock better pay, better shifts, new areas, new stations, authority, tools, and new kinds of chaos as they rank up.

## Rank Path

1. New Hire
2. Trainee
3. Crew Member
4. Fry Cook / Kitchen Worker
5. Register Goblin
6. Drive-Thru Window Warrior
7. Crew Trainer
8. Shift Lead
9. Key Holder
10. Assistant Manager
11. Store Manager

## Rank Design Requirements

Each rank must define:

- display name
- pay rate
- accessible areas
- unlocked stations
- unlocked authority
- unlocked tools
- shift types available
- new chaos/events
- promotion requirements
- demotion/setback risks
- training/certifications
- manager comments
- comedy flavor
- save fields

## Rank Summary

### New Hire
Purpose:
The player is brand new and barely trusted.

Unlocked:
- clock in/out
- basic movement
- basic interaction
- pick up/drop
- basic cleaning
- simple tutorial shift

Limitations:
- no manager office
- limited station use
- low pay
- bad shifts
- coworkers may ignore them

### Trainee
Unlocked:
- simple burger assembly
- basic fries
- drink fill
- simple handoff
- customer patience meter
- simple shift results

Chaos:
- misheard orders
- burnt food
- dropped items
- training video interruptions

### Crew Member
Unlocked:
- normal station loop
- grill/fryer/drink/bagging
- sauce rack
- better pay

Chaos:
- lunch rush
- coupon arguments
- sauce shortages
- wrong bag panic
- customer changes order at window

### Fry Cook / Kitchen Worker
Unlocked:
- cook quality
- holding timers
- prep stock
- waste tracking
- kitchen speed bonuses

Chaos:
- fryer overheat
- grill jam
- freezer stuck
- food dropped
- corporate lowers waste budget

### Register Goblin
Unlocked:
- register/payment interactions
- coupon validation
- customer recovery choices
- basic apology/coupon tools

Chaos:
- card reader failure
- exact change customer
- invalid coupon warrior
- receipt printer jam
- “I know the owner” customer

### Drive-Thru Window Warrior
Unlocked:
- drive-thru speed bonus
- pull-forward option
- window interaction choices
- line pressure meter
- honk meter
- multi-car rushes

Chaos:
- passenger-seat ordering
- loud truck customer
- dog driver
- last-second add-on
- item-counting customer

### Crew Trainer
Unlocked:
- train one coworker
- give instructions
- correct coworker mistakes
- reduce new-hire chaos
- training board

Chaos:
- new hire asks absurd questions
- coworker ignores instructions
- training slows shift
- drama magnet pulls trainee into gossip

### Shift Lead
Unlocked:
- assign coworkers to stations
- approve/deny breaks
- handle minor complaints
- resolve basic employee drama
- shift checklist
- station coverage board

Chaos:
- coworker calls out
- employee hides
- break room argument
- customer demands manager
- corporate calls mid-rush

### Key Holder
Unlocked:
- open store
- close store
- count register
- restricted areas
- check inventory
- alarm/call-in event
- more office tools

Chaos:
- opening prep missing
- closing disaster
- alarm false call
- register mismatch
- truck delivery arrives badly

### Assistant Manager
Unlocked:
- build basic schedule
- assign staff before shift
- train employees
- handle HR reports
- choose small upgrades
- respond to reviews
- use office computer

Chaos:
- bad schedule
- time-off requests
- inspection warning
- review storm
- staff conflict chain
- blamed for everything

### Store Manager
First major win condition.

Unlocked:
- full store responsibility
- hiring/firing/coaching
- scheduling
- upgrades
- equipment purchases
- training plans
- office access
- review response
- corporate calls
- inspection prep
- policy choices
- customer ban/rival system
- local marketing
- inventory planning
- shift planning
- future district manager hooks

Store Manager should change gameplay, not end it.
