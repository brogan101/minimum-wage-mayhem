# V20 Consequence Matrix System

Every action/event/mission/prank/shady choice should run through a central consequence matrix.

## Calculate

- cash delta
- tip delta
- XP delta
- time lost
- customer Beef
- customer patience
- staff morale
- coworker loyalty
- manager trust
- manager suspicion
- corporate approval
- store stability
- cleanliness
- inventory
- suspicion
- evidence created
- karma changes
- HR report chance
- review chance
- viral clip chance
- promotion progress
- demotion risk
- fired risk
- future chain chance

## Context Matters

The same action should not always produce the same result.

Example:
Taking from tip jar during low chaos with Corporate Climber nearby is high risk.

Taking from tip jar during huge rush with checked-out manager and loyal coworker nearby is lower detection risk, but suspicion still increases and a cold-case side quest may trigger later.
