# Manager Trial Shift

## Purpose

Becoming Store Manager should have a real climax.

The Manager Trial Shift is the first major campaign boss shift.

## Trigger

Unlocked after:
- Assistant Manager rank
- required training complete
- acceptable reliability
- acceptable customer satisfaction
- active write-ups below limit
- at least one acting-manager shift complete
- manager evaluation score high enough

## Setup

- Store Manager is gone.
- Player is acting manager.
- One coworker calls out.
- Corporate goal appears.
- Rush happens.
- One customer Beef event occurs.
- One equipment issue occurs.
- One employee drama issue occurs.
- Player must keep store operating.

## Success

Passing does not require perfection.

Pass if:
- shift completes
- store does not collapse
- minimum customer satisfaction met
- major issue handled or contained
- staff morale not destroyed
- corporate goal partially or fully addressed

## Failure

If failed:
- promotion delayed
- recovery goals assigned
- funny HR report generated
- manager comments added
- player can retry later

## Possible Trial Variants

- Lunch Rush Trial
- Closing Disaster Trial
- Corporate Inspection Trial
- Understaffed Trial
- Mystery Shopper Trial
- Equipment Meltdown Trial
- Staff Drama Trial
- Coupon Convention Trial

## Reward

If passed:
- promoted to Store Manager
- full manager office access
- schedule control
- hiring/firing/coaching tools
- store upgrade planning
- post-manager campaign hooks
