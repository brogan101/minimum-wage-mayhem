# No-Scripted-Quest Rule

The game must not rely on one fixed list of quests that always happen the same way.

A mission should be generated from current state:

- shift type
- player rank
- player reputation
- current manager archetype
- coworker relationships
- active customer rivals
- store condition
- corporate pressure
- home-life modifier
- recent incidents
- karma
- suspicion
- evidence
- staff morale
- manager trust
- prank heat
- shady heat
- active write-ups
- promotion progress
- random seed

## Example

Do not create one fixed mission called Tip Jar Theft.

Instead, create a Tip Jar Incident Generator that can produce:

- player took from tip jar
- coworker took from tip jar
- manager moved jar
- customer took jar
- New Hire misunderstood jar
- Sauce Hoarder converted tips to sauce currency
- Corporate Climber falsely accused someone
- jar was moved during prank
- player is innocent but suspicious
- player is guilty but someone else gets blamed
- cold-case side quest returns later

## Rule

Hardcoded legendary chains are allowed as rare curated anchors, but normal missions should emerge from system state.
