# Restaurant Story Event Bank

This file summarizes the restaurant story-event bank.

The data version lives in:

`data/mischief/restaurant_story_events.json`

Events are grouped as:
- drive_thru
- sauce
- register_payment
- food_kitchen
- lobby_counter
- coworker
- manager
- corporate
- prank
- home_outside
- review_viral

Rules:
- Events must be fictionalized.
- Do not use real brands, real names, exact posts, exact quotes, usernames, or videos.
- Transform real patterns into fictional mechanics.
- Every event needs tags, severity, systems affected, and fallback.
