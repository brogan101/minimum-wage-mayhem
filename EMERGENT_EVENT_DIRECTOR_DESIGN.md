# Emergent Event Director Design

## Purpose

Build events from components instead of always selecting fixed scenes.

## Event Formula

Actor + Problem + Location + Object + Witness + Cover Story + Immediate Consequence + Delayed Consequence + HR Interpretation + Review Interpretation + Career Impact

## Example

Actor:
New Hire

Problem:
Believed a fake policy

Location:
Drive-thru window

Object:
Receipt printer

Witness:
Coupon Warrior customer

Cover Story:
Corporate said the receipt printer is in charge now.

Immediate Consequence:
Customer Beef increases.

Delayed Consequence:
Corporate Climber reports policy confusion.

HR Interpretation:
Unauthorized Receipt-Based Leadership

Career Impact:
Player gains prank suspicion and loses manager trust unless they fix it.

## Rules

- Generated events must use compatible components.
- Components need tags.
- Events must record EventLog entries.
- Events must be eligible for recap.
- Severe events must be gated by rank/tutorial/chaos budget.
- Events should create future chain chances.
