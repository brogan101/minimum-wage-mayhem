# Restaurant Memory System

## Purpose

The restaurant must remember.

Memory should track:
- events
- people involved
- locations
- objects
- witnesses
- evidence
- suspects
- blame
- rumors
- HR interpretations
- reviews
- outcomes
- future chain flags
- object reputation changes
- player reputation changes
- career consequences

## Memory Types

- shift memory
- career memory
- staff memory
- customer memory
- object memory
- rumor memory
- corporate memory
- HR memory
- evidence memory
- home-life memory

## Rule

Memory should feed future missions, dialogue, reviews, manager reactions, customer rivals, object labels, and recaps.
