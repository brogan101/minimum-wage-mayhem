# Emergent Mission Generator Design

Missions should be created from:

- problem type
- suspect / actor
- location
- object
- time pressure
- witnesses
- evidence
- player history
- reward
- risk
- branching options
- possible failure states
- delayed consequences

## Mission Template

Mission Name:
Generated from components.

Trigger:
Why this mission appeared.

Context:
What happened and who cares.

Objectives:
- main objective
- optional objective
- hidden objective

Choices:
- honest route
- shady route
- lazy route
- aggressive route
- prank route
- manager route
- coworker loyalty route

Failure:
What happens if ignored or failed.

Success:
What happens if resolved well.

Partial Success:
What happens if resolved badly but not catastrophically.

Future Consequence:
What can trigger later.
