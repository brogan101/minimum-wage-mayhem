# Dynamic Reputation Labels System

Reputation labels should be earned from actual behavior and affect future gameplay.

## Example Labels

- Sauce Criminal
- Customer Whisperer
- Walking HR Report
- Food Karma Fugitive
- Staff Hero
- Corporate Pet
- Drive-Thru Demon
- Mop Menace
- Register Goblin
- Shift Savior
- Break Room Goblin
- Manager Material Somehow
- Ethically Medium Rare
- Future Store Manager
- Somehow Still Employed

## Labels Affect

- dialogue
- event odds
- manager reactions
- coworker trust
- customer behavior
- promotion path
- HR reports
- reviews
- recap tone
