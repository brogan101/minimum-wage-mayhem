# Phase 1 — Boot + 3D Player + Input

## Goal
The game boots to a 3D scene with a controllable player.

## Tasks
- Open project in Godot 4.x.
- Fix any parse errors Godot reports.
- Confirm `scenes/world/Main.tscn` is main scene.
- Confirm player spawns.
- Confirm keyboard/mouse movement/look.
- Confirm controller-compatible InputMap actions.
- Add/verify pause action.
- Add minimal debug/HUD proof if missing.

## Do Not Do
- DLC.
- Full content expansion.
- Manager mode.
- Home chaos.

## Acceptance
- User can launch scene and walk around.
- Controls work through input actions.
- Validation passes or failures are documented.
