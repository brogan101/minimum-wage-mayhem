# File Inclusion Manifest

Date: 2026-06-04

## Goal

Create a clean GitHub-ready repository for Minimum Wage Mayhem that includes real game, build, data, validation, and current development-tracking files while excluding local caches, binaries, prompts, archive clutter, screenshots, and generated artifacts.

## Included

| Pattern/File | Reason |
|---|---|
| `.gitignore` | Defines Godot 4 and workspace hygiene rules. |
| `project.godot` | Required Godot project config and autoload/input map source. |
| `scenes/` | Required playable Godot scenes. |
| `scripts/` | Required GDScript gameplay/runtime source. |
| `data/` | Required local JSON gameplay catalogs and story-event lock data. |
| `assets/` | Current license-safe repo asset source; currently shader-only. |
| `tools/*.py` | Static validators needed for `python tools/validate_all.py`. |
| `tools/*.gd` | Godot runtime smoke checks for phases 2-19. |
| `tools/*.ps1`, `tools/*.sh` | Repo-local Godot setup/run helper scripts, without bundled binaries. |
| `README.md` | Player/developer entry point. |
| `ASSET_ATTRIBUTION.md`, `ASSET_CREDITS.md`, `ASSET_REQUIREMENTS_V15.md`, `ASSET_SOURCING_PLAN.md`, `ASSET_VALIDATION.md` | Asset/license tracking and requirements. |
| `EXPORT_NOTES.md`, `STEAM_READINESS_CHECKLIST.md`, `PLAYTEST_CHECKLIST.md` | Build/playtest/release prep docs. |
| `KNOWN_ISSUES.md`, `IMPLEMENTATION_STATUS.md`, `VALIDATION_REPORT.md`, `PHASE_LOG.md`, `SOLO_SHIFT_ACCEPTANCE_TEST.md` | Current repo status and required end-of-phase tracking. |
| `PROJECT_SOURCE_OF_TRUTH.md`, `CODEX_START_HERE.md`, `AGENTS.md` | Current source-of-truth reading order and project rules. |
| `PHASE_0_*.md` through `PHASE_14_*.md`, `PHASE_16_*.md`, `PHASE_17_*.md`, `PHASE_18_*.md`, `PHASE_19_*.md` | Active phase briefs/reports needed for dev tracking and validator context. |
| `PHASE_RUN_ALL_PROMPT.txt`, `RUN_ALL_PHASES_PROMPT_COPY_THIS.txt`, `V23_FINAL_AUDIT_REPORT.md`, `V22_RESTAURANT_STORY_EVENT_COUNT_LOCK.json` | Required by the current validator/source-of-truth chain. |
| Root system design docs such as `CAREER_LADDER_SYSTEM.md`, `RESTAURANT_MEMORY_SYSTEM.md`, and related concise system docs | Small current design references for implemented local systems. |

## Excluded

| Pattern/Folder | Reason |
|---|---|
| `.godot/`, `.import/`, `*.import` | Godot editor/import cache; regenerated locally. |
| `tools/downloads/`, `tools/bin/`, `*.zip` | Local Godot binaries/download archives; too large and regenerated by setup scripts. |
| `artifacts/` | Generated screenshots/proof images; not required to build/test. |
| `tools/__pycache__/`, `*.pyc` | Python cache files. |
| `.env*`, `*.key`, `*.pem`, `*.secret` | Secret/config safety. |
| `.vscode/`, `.idea/`, OS junk | Machine/editor local state. |
| `PHASE_PACK/` | Large historical V13 reference/prompt pack; not required for build/test. Current summaries live in Phase 16/source-of-truth docs. |
| `disabled_not_in_scope/` | Disabled multiplayer/local co-op material, intentionally out of current single-player scope. |
| `CODEX_RUN_ALL_PHASES_PROMPT_V21.txt`, `CODEX_PHASE_7_PROMPT.txt` | Historical prompt duplicates/clutter. |
| `V*_VALIDATION*`, `V*_VALIDATE_ALL_*`, `V*_NEW_FILE_MANIFEST.json`, `V20_SOURCE_PROMPT_IMPORTED.md` | Historical validation snapshots/import prompts; current validation lives in tools and status docs. |
