# File Inclusion Manifest

Date: 2026-06-06

## Goal

Keep the GitHub repo buildable, testable, and reviewable while excluding local Godot caches, downloads, generated artifacts, prompt clutter, local saves, and secrets.

| Pattern/File | Reason |
|---|---|
| `.gitignore` | Godot 4 and workspace hygiene rules. |

## Excluded

| Pattern/Folder | Reason |
|---|---|
| `.godot/`, `.import/`, `*.import` | Godot editor/import cache; regenerated locally. |
| `tools/downloads/`, `tools/bin/`, `*.zip`, `*.7z`, `*.rar` | Local Godot binaries/download archives; too large and regenerated by setup scripts. |
| `artifacts/` | Generated screenshots/proof images; not required to build/test. |
| `tools/__pycache__/`, `*.pyc`, `.pytest_cache/`, `.mypy_cache/` | Python cache files. |
| `savegame.json`, `*.save`, `*.tmp`, `*.temp` | Local runtime save/temp data. |
| `.env*`, `*.key`, `*.pem`, `*.secret` | Secret/config safety. |
| `.vscode/`, `.idea/`, OS junk | Machine/editor local state. |
| `PHASE_PACK/` | Large historical V13 reference/prompt pack; not required for build/test. |
| `disabled_not_in_scope/` | Disabled multiplayer/local co-op material, intentionally out of current single-player scope. |
| Historical prompt duplicates and `V*_VALIDATION*` snapshots | Current validation lives in tools and status docs. |
