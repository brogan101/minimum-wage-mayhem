# V15 Asset / Texture / Model / Audio Requirements

Every new system must either use a verified CC0/commercial-use asset or a procedural fallback.

Priority asset needs:
- drive-thru window
- customer cars
- food bag
- sauce packets
- HR printer
- phone/group chat UI
- apartment props
- mop
- energy drink can
- manager clipboard
- fryer/grill/drink station audio hooks
- customer reaction stingers

Approved source plan:
- Poly Haven / ambientCG for CC0 textures
- Kenney for CC0 game assets/icons/audio when suitable
- Quaternius for low-poly models if license verified
- Procedural Godot primitives as fallback

No real restaurant branding. No unverified assets. No ripped game assets.
