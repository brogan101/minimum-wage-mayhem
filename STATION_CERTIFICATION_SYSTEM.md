# Station Certification System

## Purpose

The player should earn trust by proving station skill.

## Certifications

- Cleaning Basics Certification
- Burger Assembly Certification
- Fryer Certification
- Drink Station Certification
- Bagging Certification
- Register Certification
- Drive-Thru Certification
- Sauce Control Certification
- Opening Checklist Certification
- Closing Checklist Certification
- Trainer Certification
- Shift Lead Certification
- Manager Readiness Certification

## Certification Mission Structure

Each certification should have:
- unlock rank
- tutorial requirement
- challenge shift
- pass condition
- partial pass
- failure consequence
- retry rules
- funny evaluator comments
- promotion requirement link

## Example: Fryer Certification

Goal:
Serve a rush segment with fries cooked correctly and limited waste.

Possible chaos:
- fryer overheats
- coworker steals fries
- customer demands fresh fries
- corporate wants waste reduced

Pass:
- quality threshold met
- waste below limit
- no major fire/incident

Fail:
- forced retraining
- funny HR note
- retry after one shift
