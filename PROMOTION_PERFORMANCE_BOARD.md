# Promotion / Performance Board

## Purpose

The career ladder should be visible in the 3D world.

Create a physical board or office screen that shows the player what they need to do next.

## Display Fields

- current rank
- next rank
- pay rate
- promotion progress
- required shifts
- order accuracy
- speed score
- customer rating
- Beef control
- write-ups
- training/certifications
- manager comments
- staff morale
- corporate approval
- reliability
- active setbacks
- next required milestone

## Possible Locations

- break room
- manager office
- training computer
- schedule board
- employee performance board

- “Fryer respects you more than management does.”

- “Manager voice: locked.”
- “Clipboard aura: developing.”
