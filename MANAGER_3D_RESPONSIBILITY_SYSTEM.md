# Manager Responsibilities Must Affect 3D Gameplay

## Rule

Manager mode must not become a menu-only spreadsheet.

Every manager choice should affect physical shifts.

## Examples

| Manager Choice | 3D Shift Consequence |
|---|---|
| Schedule too few employees | station uncovered, player runs more |
| Train employee | fewer mistakes, more helpful NPC |
| Overwork staff | call-out chance and morale issues |
| Buy better fryer | faster fries / fewer overheat events |
| Ignore cleaning | inspection risk / spills / customer complaints |
| Buy cheap supplies | more customer complaints |
| Fire too many employees | staffing instability |
| Promote good worker | station boost |
| Ignore group chat drama | staff starts angry |
| Improve morale | coworkers save player during rush |

## Manager Timing

Manager decisions happen:
- before shift
- during shift under pressure
- after shift in results/office

## Manager Tools

- schedule board
- staff assignment board
- HR report stack
- review response terminal
- upgrade board
- inventory sheet
- training computer
- corporate phone
- inspection checklist

## Validation

Every manager feature must define:
- decision
- immediate consequence
- next-shift consequence
- staff effect
- customer/store effect
- EventLog/HR/review hook
