# Shady UI Choice System

## Purpose

All shady/fireable actions happen through simple click/choose UI interactions.

The player interacts with objects or NPCs, then chooses from abstract options.

## Interactable Objects

- coworker
- customer
- manager
- register
- tip jar
- food bag
- sauce rack
- break room item
- manager tablet
- office computer
- security monitor
- HR printer
- corporate phone
- drive-thru window
- storage shelf
- trash area
- freezer
- cash drawer
- prank object
- evidence object

## Example: Tip Jar

Choices:
- Leave it alone
- Count tips honestly
- Take a little
- Blame missing tips on customer
- Move tip jar for safety
- Tell coworker to watch it
- Report coworker for staring at it

## Example: Manager Coverup

Choices:
- Go along
- Refuse
- Ask what is in it for me
- Tell coworker
- Save evidence
- Report to corporate
- Pretend not to know
- Use this later for promotion leverage

## Required Effects

Each choice should affect at least one:
- suspicion
- witnesses
- camera risk
- coworker loyalty
- manager trust
- corporate approval
- shady karma
- tip income
- HR risk
- promotion progress
- demotion risk
- fired risk
- EventLog
- end-of-shift recap
