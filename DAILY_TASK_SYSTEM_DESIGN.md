# Daily Task System Design

Each shift should generate optional daily tasks.

Categories:
- normal
- fast_food_chaos
- manager
- prank
- karma

Daily tasks should:
- be optional
- give minor XP/cash/morale/reputation rewards
- teach systems
- create side content without derailing shift
- have fallback tasks if generation fails

## Task Types

Normal:
- restock sauce
- clean lobby
- prep buns
- fill ice
- stock bags

Chaos:
- calm one angry customer
- survive lunch rush
- handle one coupon dispute
- prevent customer from blocking window

Manager:
- complete opening checklist
- assign coworker to station
- respond to review
- handle callout

Prank:
- pull harmless prank without getting caught
- discover who pranked player
- end prank war peacefully

Karma:
- fix mistake honestly
- help coworker you dislike
- redeem bad review
