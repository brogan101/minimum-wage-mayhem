# Rank-Based Area Unlocks

## Purpose

Promotions should be visible in the 3D restaurant. The building should open up as the player earns trust.

## Area Unlock Table

| Rank | Areas / Tools Unlocked |
|---|---|
| New Hire | lobby basics, simple cleaning, clock-in area |
| Trainee | basic kitchen path, drink station, bagging station |
| Crew Member | grill, fryer, sauce rack, hot holding |
| Fry Cook | walk-in/cooler, prep bins, kitchen timers |
| Register Goblin | front counter/register, receipt printer, coupon UI |
| Drive-Thru Window Warrior | speaker/window focus, pull-forward controls, line meter |
| Crew Trainer | training computer, trainee checklist, coaching prompts |
| Shift Lead | assignment board, break approval, station coverage board |
| Key Holder | opening/closing checklist, restricted storage, register count tools |
| Assistant Manager | office computer, HR reports, review response, schedule draft |
| Store Manager | full manager office, upgrade board, staff controls, policy tools |

## Rules

- Locked areas should exist physically but be inaccessible.
- Unlocks should be announced through promotion results.
- Locked interactions should show funny denial text.
- Higher rank means more control but also more blame.

## Funny Locked-Area Examples

- “Manager office requires at least 3 more emotional scars.”
- “Corporate says you are not clipboard-certified.”
- “The schedule board senses your lack of authority.”
- “This door opens when the fryer respects you.”
