# Store Operations Duties

## Purpose

The restaurant should feel like a real workplace. Boring duties make the chaos matter.

## Opening Duties

- turn on equipment
- stock stations
- check freezer/cooler
- prep food
- count register
- clean lobby
- review schedule
- read corporate note
- handle late employee
- check drive-thru headset

## Mid-Shift Duties

- serve customers
- restock ingredients
- cook food
- handle complaints
- clean spills
- manage station coverage
- watch timers
- keep drive-thru moving
- handle rush waves
- maintain morale
- keep bathroom/lobby from collapsing

## Closing Duties

- clean equipment
- count register
- throw away old food
- lock doors
- restock for morning
- submit report
- handle last-minute customer
- deal with coworker trying to leave early
- check manager notes

## Unlock Rule

New Hire should not do everything.

Opening/closing and inventory duties should unlock through Key Holder, Assistant Manager, and Store Manager progression.

## Gameplay Rule

Each duty should either:
- affect next shift
- affect inspection risk
- affect inventory
- affect reputation
- affect staff morale
- create a funny event if ignored
