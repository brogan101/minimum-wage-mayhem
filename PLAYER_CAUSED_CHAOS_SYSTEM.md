# Player-Caused Chaos System

The player should not only react to chaos. The player should be able to accidentally or intentionally create it.

## Player Actions That Can Cause Chaos

- use savage comeback
- deny sauce
- give too much sauce
- serve wrong bag
- ignore spill
- join gossip
- hide in freezer
- blame New Hire
- blame register
- call manager too often
- ignore corporate call
- use manager voice before promoted
- start fake policy
- forget closing duty

## Consequences

- staff morale change
- customer Beef change
- manager trust change
- corporate approval change
- HR report
- review
- write-up
- promotion boost/delay
- demotion risk
- reputation label
- future event chain
- legendary incident unlock
