# Phase 3 — Stations + Food State

## Goal
One station processes one food item with visual feedback.

## Tasks
- Add grill or fryer station to scene.
- Add one FoodItem.
- FoodItem changes RAW -> COOKED -> BURNT.
- Visual color/state feedback works.
- Station status is visible/debuggable.
- EventLog records item state changes.

## Acceptance
- Player can place/use food at one station and see a state change.
